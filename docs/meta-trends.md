# 최근 메타 변화

- 입력: 공식 랭크 스쿼드 전적 JSONL 또는 gzip JSONL 폴더. 최신 시즌만 사용한다.
- 실제 `startedAt` 기준으로 한국 시간의 완료된 최근 7일과 이전 7일을 비교한다. 수집일을 경기일로 쓰지 않는다.
- `gameId + teamKey`로 중복을 제거하고, 실험체·무기를 구분한다. 같은 팀의 세 가지 추천 관점으로 경기 수를 부풀리지 않는다.
- 1인 픽, 2인 조합, 3인 조합의 팀 단위 사용 비중을 계산한다. 전체 티어에서는 양 기간에 동일한 티어 가중치를 적용해 수집 티어 구성 변화의 영향을 줄인다.
- 양 기간 각각 5일 이상, 티어별 100팀 이상, 비교 대상 전체 1,000팀 이상이 필요하다. 2인 조합의 변화 후보는 각 기간 표본 40팀 이상, 증가 비율 1.5 이상 또는 감소 비율 1/1.5 이하, 비중 변화 절댓값 0.01%p 이상, |z| ≥ 2.58 및 BH FDR 0.1 조건을 충족해야 한다. 실험체 단독과 3인 조합의 별도 기준은 아래와 같다.
- 출시·랭크 제한으로 이전 주 전체를 비교할 수 없는 신캐는 해당 픽과 이를 포함한 모든 조합을 변화 순위에서 보류한다. `src/characterAvailability.js`에 공식 공지의 랭크 제한 종료 후 첫 완전한 날짜를 기록한다. 세레스는 12.5 공지의 10월 6일까지 제한을 근거로 10월 7일을 사용한다([공식 게시자 미러](https://game.naver.com/lounge/Eternal_Return/board/detail/8265647)). 두 비교 구간 모두 이 날짜 이후일 때 자동으로 재평가한다.
- 출시일을 모르는 향후 실험체나 뒤늦게 수집된 실험체도 두 기간 각각 7일 전체에서 관측돼야 비교한다. 날짜별 관측은 해당 픽의 무기별 조합이 아니라 캐릭터 단위로 확인하고, 각 조합의 표본 하한은 별도로 적용한다.
- 3인 조합은 희소성을 고려해 합계 60경기 이상인 후보를 먼저 추리고, 3인 후보끼리 양측 BH FDR 0.1을 적용한다. 기간별 최소 20경기, 변화 비율 1.5배, |z| ≥ 2.58, 신캐/완전한 관측 기간 기준은 유지한다. 절대 사용 비중 변화 하한만 0.003%p로 별도 적용한다(2인은 기존 0.01%p 및 기존 검정 유지). 희소한 수십만 조합이 검정 수만 늘려 충분한 표본의 변화를 가리지 않게 한다.
- 실험체 단독은 조합과 빈도가 달라 별도 효과 기준을 적용한다. 양 기간 최소 60경기, 변화 비율 1.15배 이상(감소는 역수), 절대 비중 변화 0.25%p 이상이 필요하다. 증가·감소에 같은 기준을 쓰며 기존 양측 BH FDR 0.1, |z| ≥ 2.58, 신캐 보류와 기간 검증을 유지한다. 2·3인 조합 기준은 유지한다.
- 표시되는 변화는 사용 비중의 증가·감소다. TOP3 비율은 해당 최근 표본의 성적을 따로 보여준다. 승률 상승이나 인과적 우위를 뜻하는 점수로 사용하지 않는다.
- 양측 검정을 한 뒤 상승·하락을 하나의 BH FDR 보정 집합에 넣는다. 티어·인원수·방향별 최대 10개를 생성하고, 화면에서는 방향별 변화 폭이 큰 최대 6개씩 증가 묶음 다음에 감소 묶음으로 하나의 좌우 막대 차트에 표시한다. 같은 0 중심선과 막대 배율을 사용하되 상단 최대치 표시는 생략하며 왼쪽 빨강은 감소, 오른쪽 청록은 증가다. 충분한 자료가 없으면 다른 티어 또는 전체 누적 인기 조합으로 대체하지 않는다. 오래된 요약은 갱신 대기 상태로 표시한다.

```powershell
node tools/build_meta_trends.mjs --in data/ml-training/corpus.jsonl --out src/metaTrends.json
node tools/test_meta_trends.mjs
node tools/test_meta_movement.mjs
node tools/test_trait_selection.mjs
```

`src/metaTrends.json`과 `src/metaTrends.js`는 생성 파일이다. 기존 6시간 수집 workflow에서 재생성해 함께 커밋한다. 앱은 번들 요약을 즉시 표시하고 더 최신인 원격 요약이 있으면 교체한다. 별도 유료 서비스나 브라우저에서의 원시 전적 분석은 필요하지 않다.

특성 선택은 `slotCores` 한곳에서 관리한다. 내 픽과 아군 선택, 추천 계산, 조합 설명 및 평가 대상 ID가 같은 선택값을 사용한다. 평가 버튼을 누르기 전에는 서버에 평가를 전송하지 않는다.

## 2026-10-15 3인 기준 점검

동일한 462,972팀 비교 자료에서 신캐/관측일 검사를 통과한 3인 후보는 119,161개였으나, 합계 60경기 이상의 비교 후보는 112개였다. 기존 검정은 희소한 후보까지 모두 포함해 검정 수만 늘어났고, 3인 감소 1개만 남았다. 3인 전용 사전 빈도 필터/검정과 변화 폭 기준을 적용한 결과 증가 2개·감소 9개가 검출됐다. 화면은 방향별 최대 6개 규칙을 유지한다. 최소 기간별 20경기 및 신캐 기준을 낮추지 않았다.

추후 점검은 `--diagnostics-out reports/generated/meta-trends-diagnostics.json`으로 후보별 탈락 조건을 보관할 수 있다. 이 진단 자료는 앱 요약에 포함되지 않는다.
