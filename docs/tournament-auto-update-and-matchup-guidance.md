# 대회 자동 갱신과 상대 조합 안내 — 2026-10-13

대회 자료를 직접 찾아 입력할 필요를 줄이도록 기존 일일 수집을 복구했고, 실제 3인 무기·코어 빌드를 비교하는 조건부 상대 안내를 추가했다.

## 자동 갱신

기존 Collect Tournament Games는 매일 실행됐지만 경기 7727~7751이 비어 있어 25번의 누락 후 종료했다. 공개된 최신 경기 8041까지의 번호 간격을 건너뛰지 못한 것이 원인이었다. 이제 [DAK.GG 대회 페이지](https://dak.gg/er/esports?hl=en)가 사용하는 공개 recent-games 목록을 페이지별로 읽고, 현재 시즌에 공개된 미수집 경기만 조회한다. 나중에 등록된 낮은 번호도 다시 찾고, 새 시즌도 목록에서 알아낸다. 정상 목록이 아니거나 요청이 실패하면 이전 자료를 덮어쓰지 않는다. 오래된 불완전 기록은 무기·코어를 한 번 보완하며, 알 수 없는 무기를 첫 번째 무기로 임의 대체하지 않는다.

실제 수집: 22→123경기, 팀 기록 984개. 새 경기 101개를 가져왔고 기존 22경기를 보완했다. 캐릭터 조합 172개(2회 이상), 무기·코어별 빌드 291개, 해당 빌드로 식별된 팀 기록 971개다. 나머지 13개는 현재 빌드 식별 기준으로 구분하지 못해 상대 예시에서 제외한다. 가장 최근 경기 시각은 2026-10-11 20:17:59 KST다. DAK.GG에 등록되지 않은 대회는 자동으로 포함되지 않는다.

기존 GitHub Actions 일정은 매일 15:15 KST 예약이며 실제 시작은 GitHub 대기열에 따라 늦어질 수 있다. 신규 경기가 없으면 집계 재생성·스냅샷 갱신·커밋을 생략한다. 충돌이나 검증 실패를 강제로 무시하지 않는다. 앱은 시작할 때와 열린 상태에서 4시간마다 62.7KB의 대회 JSON을 확인한다. 변경된 자료는 추천 인덱스와 캐시에도 반영하며, 열려 있는 유니온 결과는 다시 계산한다. 읽기 실패 시 번들 자료를 유지한다. 데이터만 바뀐 커밋은 Vercel 전체 재배포를 생략할 수 있어 무료 저장 공간을 아낀다. 새 유료 서비스는 추가하지 않았다.

## 상대 조합 안내

추천 후보의 펼친 내용, 내 픽 기준 전체 팀 추천, 현재 선택 팀의 상세 설명, 유니온 추천 카드에서 ‘상대 조합 체크’를 볼 수 있다. 실제 캐릭터+무기 3인 팀을 비교하고, 선택한 코어 또는 표시 기본 코어의 역할·보호 태그를 반영한다. 상대 예시는 실제 대회에 관측된 무기·코어 빌드만 사용하며 코어 아이콘과 관측 횟수를 보여준다.

주의 조건은 후방 보호 부족 대 연속 진입, 선진입 중심 팀 대 진입 저지·받아치기, 접근이 필요한 팀 대 원거리 견제·지역 장악이다. 유리하게 운영할 조건은 보호·제어를 남겨 근접 진입을 받아치기, 보호가 없는 원거리 팀을 함께 잡기, 진입 수단이 적은 근접 팀에 거리·입구를 유지하기다. 같은 상대에서 구체적인 위험이 확인되면 유리 조건으로도 표시하지 않는다. 판단할 근거가 없으면 뚜렷한 조건을 찾지 못했다고 표시한다.

이것은 전투 구조에 근거한 전술적 예상이다. 앞선 4,260경기 순위 분석에서 검증되지 않은 상대별 교전 승률을 만들거나 통계적 상성을 확정하지 않는다. 화면에도 그 한계를 표시한다. 관측 빈도는 수집한 대회 표본이며 현재 로비, 전체 랭크 또는 현재 패치의 분포를 자동 감지한 것이 아니다. 장비·숙련도·교전 위치·제3팀 개입에 따라 달라질 수 있다. 새로운 가중치를 추천 점수에 넣지는 않았다.

## 검증

- 실제 네트워크 수집으로 누락 101경기와 과거 22경기를 보완했고, 재실행에서 신규 0경기·오류 0건을 확인했다.
- 목록의 큰 번호 간격, 늦게 등록된 낮은 번호, 새 시즌, 새 자료 없음, 빈 목록·스키마 오류·페이지 제한, 중복 팀, 무기·코어 보존, 원격 추천 인덱스 갱신, 잘못된 원격 자료 거부를 검사했다.
- 실제 팀에서 보호가 있는 경우와 없는 경우, 같은 루크의 치유 드론/응징에 따른 안내 변화, 실제 관측 빌드만 예시로 선택하는 동작과 5언어를 검사했다.
- 기존 추천 스냅샷 135건, 전체 팀 캐시(대회 버전 포함 8개 입력), 유니온 맥락·오래된 결과 배제, 화면 전환, 랭킹 캐시, 세레스·이미지·코드 매핑, Vercel 데이터 전용 빌드 생략, 문법·워크플로 YAML 검사를 통과했다.
- 로컬 브라우저에서 전체 팀 추천 및 현재 선택 팀의 상세 안내를 확인했다. 3원거리 팀에는 주의 조건, 보호를 둔 팀에는 받아칠 조건과 실제 대회 예시가 표시됐다.
